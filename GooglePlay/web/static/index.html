使用说明

  1. 服务账号App 和当前电脑上的 service account JSON 可按任意顺序选择；两项齐全后自动核对。
  2. 上传 Excel先查看或下载格式示例，再填写包名并上传同结构的 Excel 做本地校验。
  3. 检查差异逐项读取商品、Base plan、首周优惠、激活状态和有效价格点；出现阻塞项时必须返回修正。
  4. 自动提交输入完全一致的包名并确认一次；服务端直接同步全部内容，异常时自动恢复，最后统一核对实际结果。
任务保存在这台 Mac。刷新页面不会停止正在运行的任务；更换凭证或清空表格会重置当前工作流。
